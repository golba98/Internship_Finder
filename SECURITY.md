# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this project, please email jordanvorster404@gmail.com with:

1. A clear description of the issue and the components affected.
2. Steps to reproduce the problem, including any inputs or commands used.
3. Any potential impact or mitigation suggestions.
4. Your contact information so we can follow up.

## Response Process

We aim to respond to reports within 3 business days, acknowledge receipt, and coordinate any necessary fixes. Please allow us time to investigate before disclosing details publicly.

## Supported Versions

The latest commit on the default branch is considered maintained. Security fixes target that branch first.

# Contributing

Thanks for helping improve the South African CS Internship Finder! Before opening a pull request, please:

1. **Keep it relevant.** Add support for new job boards, tuning the scoring logic, or improving the GUI experience.
2. **Avoid sensitive data.** Never add resume files, API keys, or other personal credentials to the repo.
3. **Document behavior.** Update the README if you change command-line usage, dependencies, or default filtering criteria.
4. **Run formatting/checks.** `python -m py_compile index.py gui.py` ensures the Python syntax stays clean.

Respect the terms of the scanned job boards and be mindful of request frequency when you test scraping code. Thanks!
